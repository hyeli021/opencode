# Habit Tracker

간단한 습관( Habit ) 기록 웹앱입니다. HTML / CSS / Vanilla JavaScript / localStorage 만 사용했고, 외부 라이브러리는 사용하지 않았습니다.

## 실행 방법

파일을 열기만 하면 바로 동작합니다.

```bash
open index.html
```

또는 로컬 서버를 띄워서 확인할 수도 있습니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 기능

| 기능 | 설명 |
| --- | --- |
| 습관 추가 | 입력창에 이름을 넣고 `추가` 버튼(또는 Enter) |
| 습관 삭제 | 카드 오른쪽의 쓰레기통 버튼 (확인 후 삭제) |
| 오늘 완료 체크 | 카드 왼쪽 체크박스를 클릭 |
| 완료 상태 저장 | 완료한 날짜를 `YYYY-MM-DD` 형태로 기록 |
| 새로고침 후 유지 | `localStorage`에 저장되어 지우지 않는 한 유지 |
| 오늘 날짜 표시 | 헤더에 `2026년 10월 22일 목요일` 형식으로 표시 |
| 완료 / 전체 개수 | 진행률 카드에서 완료 개수, 전체 개수, 달성률 확인 |
| 카드형 UI | 각 습관을 개별 카드로 표시 |
| 모바일 반응형 | 480px 이하에서는 한 줄 배치 + 입력 폼 세로 배치 |

추가로 **전체 / 완료 / 미완료 필터**, **연속 달성 일수 & 누적 완료 횟수**, **다크 모드**(시스템 설정 연동)를 지원합니다.

## 파일 구성

```
habit-tracker/
├── index.html   # 화면 구조 (헤더, 진행률 카드, 추가 카드, 목록 카드)
├── style.css    # 스타일 (CSS 변수, 카드 UI, 반응형 레이아웃)
├── script.js    # 로직 (데이터 저장/불러오기, 렌더링, 이벤트 처리)
└── README.md
```

## 데이터 구조 (localStorage)

키 이름은 `habitTracker.habits.v1` 이고, 값은 JSON 배열입니다.

```json
[
  {
    "id": "1730000000000a1b2c",
    "name": "물 2잔 마시기",
    "createdAt": "2026-10-20",
    "completions": {
      "2026-10-20": true,
      "2026-10-21": true
    }
  }
]
```

- `completions`의 키는 완료한 날짜, 값은 `true`입니다.
- 브라우저 개발자도구(F12) → Application → Local Storage 에서 직접 확인·수정할 수 있습니다.

## 주의할 점

- 데이터는 **지금 브라우저의 localStorage**에만 저장됩니다. 브라우저 데이터를 지우면 함께 사라집니다.
- 시크릿 모드(ognito)에서는 창을 닫으면 저장된 데이터가 삭제될 수 있습니다.
